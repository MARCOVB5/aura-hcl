# Requirements

Les exigences sont suivies dans GitHub Issues. Chaque User Story doit être liée aux parties pertinentes du cahier des charges et disposer de critères d'acceptation vérifiables.

## Domaines fonctionnels

1. Patient et séjour
2. Évaluation
3. Prescriptions
4. Agenda patient
5. Organisation des soins
6. Soignants et équipes
7. Alertes
8. Traçabilité
9. Intégration OpenEMR

## Convention

- `US-xxx` : User Story
- `TASK-xxx` : Technical Task
- `BUG-xxx` : Bug

Les identifiants sont portés par les Issues GitHub.
