# Definition of Done

Une User Story est considérée comme **Done** lorsque :

- [ ] l'implémentation est terminée ;
- [ ] les critères d'acceptation sont satisfaits ;
- [ ] les tests nécessaires sont présents et passent ;
- [ ] le code a été relu ;
- [ ] la documentation concernée est à jour ;
- [ ] le changement est intégré sans régression connue.

## Validation fonctionnelle

Après la DoD, la fonctionnalité passe en **Validated** lorsque la validation fonctionnelle / Product Owner a été effectuée.
