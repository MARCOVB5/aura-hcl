# Definition of Ready

Une User Story peut entrer dans une Sprint lorsqu'elle :

- [ ] est compréhensible par toute l'équipe ;
- [ ] décrit une valeur utilisateur claire ;
- [ ] possède des critères d'acceptation testables ;
- [ ] n'a pas de dépendance bloquante inconnue ;
- [ ] est suffisamment petite pour être réalisée dans la Sprint ;
- [ ] a été estimée par l'équipe.
