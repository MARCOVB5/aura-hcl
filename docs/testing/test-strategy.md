# Test Strategy

## Objectives

Vérifier la conformité des fonctionnalités, limiter les régressions et préparer l'intégration future avec d'autres composants du SI.

## Levels

- **Unit tests** : règles métier et composants isolés.
- **Integration tests** : base de données, API et interfaces entre composants.
- **Acceptance tests** : critères d'acceptation des User Stories.

## Traceability

Chaque User Story importante doit pointer vers les tests qui couvrent ses critères d'acceptation.
